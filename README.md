# Task 1 - Data Cleaning and Preprocessing

## Objective

The objective of this task was to clean and preprocess a raw dataset and prepare it for further data analysis.

## Dataset

Dataset used: Customer Personality Analysis / Marketing Campaign Dataset

## Tools Used

- Python
- Pandas
- Excel
- Jupyter Notebook / Google Colab
- GitHub

## Data Cleaning Process

The following data-cleaning steps were performed:

1. Loaded and inspected the raw dataset.
2. Checked the dataset structure and data types.
3. Identified missing values.
4. Handled missing values appropriately.
5. Checked and handled duplicate records.
6. Cleaned and standardized column names.
7. Standardized the customer date column.
8. Checked for inconsistent and invalid values.
9. Converted columns to appropriate data types.
10. Created useful date-related columns.
11. Performed a final data-quality verification.
12. Saved the cleaned dataset as `marketing_campaign_cleaned.csv`.

## Key Changes

- Missing values were identified and handled.
- Duplicate records were checked and removed where required.
- Column names were standardized using a consistent naming format.
- `dt_customer` was converted to a proper datetime data type.
- Numeric columns were checked for valid values and appropriate data types.
- Derived date columns were created for analysis.
- Final checks were performed to verify data quality.

## Files Included

- `marketing_campaign.csv` - Original raw dataset
- `marketing_campaign_cleaned.csv` - Cleaned dataset
- `Task_1_Data_Cleaning.ipynb` - Python/Pandas data-cleaning notebook
- `README.md` - Project documentation

## Conclusion

The raw dataset was successfully cleaned and preprocessed. The resulting dataset is structured and ready for further analysis or visualization.
